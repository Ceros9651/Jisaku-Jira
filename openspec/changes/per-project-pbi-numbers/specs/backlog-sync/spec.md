# Spec Delta

## MODIFIED Requirements

### Requirement: 同時操作の扱い
システムは、各操作を共有データの最新の内容に対して適用 SHALL する。複数の端末から同時に操作しても、別々の PBI やプロジェクトへの変更はすべて残る。同じプロジェクトで同時に PBI を作成しても、そのプロジェクトの中で PBI の番号は重複しない。同じ PBI の同じ項目を同時に変更した場合は、後から保存した値が残る。

#### Scenario: 別々の PBI を同時に編集する
- **WHEN** 端末 A のユーザーが `PBI-1` のタイトルを、端末 B のユーザーが `PBI-2` のステータスを、ほぼ同時に変えて保存する
- **THEN** 両方の端末で `PBI-1` の新しいタイトルと `PBI-2` の新しいステータスがどちらも表示される

#### Scenario: 同時に PBI を作成する
- **WHEN** あるプロジェクトの次の ID が `PBI-5` の状態で、端末 A と端末 B のユーザーがそのプロジェクトでほぼ同時に PBI を1件ずつ作成する
- **THEN** 2件の PBI は `PBI-5` と `PBI-6` になり、両方の端末に両方が表示される

#### Scenario: 別々のプロジェクトで同時に PBI を作成する
- **WHEN** 「Web」の次の ID が `PBI-5`、「Tool」の次の ID が `PBI-2` の状態で、端末 A のユーザーが「Web」で、端末 B のユーザーが「Tool」で、ほぼ同時に PBI を1件ずつ作成する
- **THEN** 「Web」に `PBI-5`、「Tool」に `PBI-2` が作られ、両方の端末に両方が表示される

#### Scenario: 別々のプロジェクトの同じ番号の PBI を同時に編集する
- **WHEN** 「Web」と「Tool」の両方に `PBI-1` があり、端末 A のユーザーが「Web」の `PBI-1` のタイトルを、端末 B のユーザーが「Tool」の `PBI-1` のステータスを、ほぼ同時に変えて保存する
- **THEN** 「Web」の `PBI-1` はタイトルだけが、「Tool」の `PBI-1` はステータスだけが変わり、両方の変更が残る

#### Scenario: 同じ項目を同時に変える
- **WHEN** 端末 A のユーザーが `PBI-1` のタイトルを「A」に、その後に端末 B のユーザーが「B」に変えて保存する
- **THEN** 両方の端末で `PBI-1` のタイトルは「B」になる
