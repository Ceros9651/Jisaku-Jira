# Spec Delta

## ADDED Requirements

### Requirement: カテゴリの保存と読み込み
システムは、共有データとエクスポートファイルに各 PBI のカテゴリを含める SHALL。カテゴリを持たない PBI を含むデータ（この変更より前の共有データ、以前のエクスポートファイル、version 1 のデータ、このブラウザに残った以前のデータ）は読み込めるものとし、その PBI のカテゴリは `タスク` とする。カテゴリが `タスク`・`バグ`・`テスト`・`運用` のどれでもない値の PBI を含むデータは、形式が不正なデータとして扱う。データ形式のバージョンは変えない。

#### Scenario: カテゴリが再読み込み後も残る
- **WHEN** ユーザーがカテゴリ `テスト` の PBI を作成し、ページを再読み込みする
- **THEN** その PBI はカテゴリ `テスト` のまま表示される

#### Scenario: エクスポートとインポートでカテゴリが保たれる
- **WHEN** カテゴリ `バグ` と `運用` の PBI があるバックログをエクスポートし、そのファイルをインポートする
- **THEN** それぞれの PBI のカテゴリは `バグ` と `運用` のままになる

#### Scenario: カテゴリの無い以前のデータ
- **WHEN** カテゴリの項目を持たない PBI-1 と PBI-2 を含むエクスポートファイルをインポートする
- **THEN** インポートは成功し、PBI-1 と PBI-2 はカテゴリ `タスク` として表示される

#### Scenario: 不正なカテゴリ
- **WHEN** ユーザーが、カテゴリが `epic` の PBI を含むファイルを選ぶ
- **THEN** カテゴリが不正であることが表示され、共有データは変更されない
