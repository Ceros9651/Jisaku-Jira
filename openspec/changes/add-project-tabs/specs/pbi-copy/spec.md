# Spec Delta

## MODIFIED Requirements

### Requirement: PBI のリンク
システムは、各 PBI を `<アプリの URL>#PBI-<番号>` の形の URL で指し示せるように SHALL する。`<アプリの URL>` は、いま開いているアプリのページの URL から、クエリ文字列とハッシュを除いたものとする。PBI の番号は全プロジェクトで重複しないため、リンクにプロジェクトは含めない。このリンクを開くと、その PBI が属するプロジェクトのタブが選ばれ、その PBI の詳細パネルが開いた状態でバックログ画面が表示される。リンクの番号の PBI がそのブラウザのどのプロジェクトにも無い場合は、詳細パネルを開かずに、最後に開いていたプロジェクトの一覧だけを表示する。

#### Scenario: リンクで PBI を開く
- **WHEN** `PBI-3` があるバックログで、ユーザーが `https://ceros9651.github.io/Jisaku-Jira/#PBI-3` を開く
- **THEN** 一覧が表示され、`PBI-3` の詳細パネルが開いている

#### Scenario: 別のプロジェクトの PBI のリンク
- **WHEN** 最後に開いていたプロジェクトが「Web」で、`PBI-3` が「Tool」にあるときに、ユーザーが `…/Jisaku-Jira/#PBI-3` を開く
- **THEN** 「Tool」のタブが選ばれて「Tool」の一覧が表示され、`PBI-3` の詳細パネルが開いている

#### Scenario: 無い PBI のリンク
- **WHEN** `PBI-9` がどのプロジェクトにも無いバックログで、ユーザーが `…/Jisaku-Jira/#PBI-9` を開く
- **THEN** 最後に開いていたプロジェクトの一覧だけが表示され、詳細パネルは開かない
