# Proposal

## Why

PBI の詳細を書いて保存したあと、いまは詳細パネルが開いたまま「保存しました」と出るだけで、一覧に戻るには毎回閉じるボタンを押す必要がある（PBI-12）。保存は編集を終える操作なので、保存できたらパネルを自動で閉じ、すぐ一覧に戻れるようにする。

## What Changes

- 詳細パネルで保存の操作（保存ボタン、タイトル欄での Enter）をして保存できたとき、詳細パネルを閉じる。URL のハッシュも、閉じるボタンで閉じたときと同じく消える。
- 入力に誤りがあって保存できなかったとき（タイトルが空、ストーリーポイントが 0 以上の整数でない）は、今までどおりパネルを開いたままエラーを表示する。
- パネルが閉じるため、保存後に出していた「保存しました」の表示をやめる。
- ステータスの変更（保存ボタンを使わず即時に反映される）では、今までどおりパネルを閉じない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `pbi-backlog`: 「PBI の詳細表示と編集」の要件に、保存できたら詳細パネルを閉じ、保存できなかったときは開いたままにすることを加える。

## Impact

- `src/components/DetailPanel.tsx`: 保存に成功したら閉じる処理を呼ぶ。`saved` の状態と「保存しました」の表示を削除する。
- `src/components/DetailPanel.module.css`: 使わなくなる `.savedNote` を削除する。
- `src/App.test.tsx`: 保存後にパネルが閉じることのテストを追加し、保存後に「詳細を閉じる」を押している既存のテストを直す。
- データの形式、保存先（ローカル・共有データ）、URL の形式は変わらない。
