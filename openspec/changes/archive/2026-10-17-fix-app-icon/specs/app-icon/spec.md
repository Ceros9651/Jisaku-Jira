# Spec Delta

## Purpose

ブラウザのタブ・お気に入り・ホーム画面で、このアプリを同じドメインの他アプリと取り違えずにチケット管理ツールとして見分けられるよう、アプリ専用のアイコンを表示する。

## ADDED Requirements

### Requirement: アプリ専用のアイコン
システムは、アプリのページにアプリ専用のアイコンを指定 SHALL する。アイコンはチケット管理ツールであることが分かる図柄（チケットやボードを表す形）とし、同じドメインで公開している他のアプリ（Yarikuri など）のアイコンと区別できなければならない。アイコンのファイルはアプリの公開パス（`/Jisaku-Jira/`）の配下から配信し、ドメイン直下のファイルに頼らない。

#### Scenario: タブにアイコンが表示される
- **WHEN** ユーザーが https://ceros9651.github.io/Jisaku-Jira/ を開く
- **THEN** ブラウザのタブにこのアプリのアイコンが表示され、Yarikuri のアイコンは表示されない

#### Scenario: お気に入りに追加する
- **WHEN** ユーザーが https://ceros9651.github.io/Jisaku-Jira/ をブラウザのお気に入りに追加する
- **THEN** お気に入りの項目にこのアプリのアイコンが表示される

#### Scenario: PBI の URL を開く
- **WHEN** ユーザーが https://ceros9651.github.io/Jisaku-Jira/#PBI-8 のように PBI のハッシュ付きの URL を開く、またはお気に入りに追加する
- **THEN** ハッシュの無い URL と同じアイコンが表示される

#### Scenario: アイコンのファイルが配信される
- **WHEN** ページの `<head>` で指定されたアイコンの URL を取得する
- **THEN** どの URL も `/Jisaku-Jira/` で始まり、画像として正常に（HTTP 200 で）返る

### Requirement: 環境ごとのアイコン
システムは、SVG のアイコンに加えて、SVG のアイコンを使わない環境向けのラスター画像のアイコンと、iOS のホーム画面に追加したとき用のアイコン（apple-touch-icon）を指定 SHALL する。どのアイコンも同じ図柄でなければならない。

#### Scenario: ホーム画面に追加する
- **WHEN** ユーザーが iPhone の Safari で公開 URL を開き、ホーム画面に追加する
- **THEN** ホーム画面にこのアプリのアイコンが表示される

#### Scenario: 小さいサイズで表示する
- **WHEN** アイコンがブラウザのタブのように 16px 四方で表示される
- **THEN** 図柄がつぶれず、チケット管理ツールの形として判別できる
