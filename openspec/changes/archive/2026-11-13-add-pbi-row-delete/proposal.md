# Proposal

## Why

PBI を削除するには、いまは一覧で行を選んで詳細パネルを開き、パネル下端の「削除」を押す必要がある。不要な PBI を片付けたいだけなのに、毎回チケットを開くのは手間がかかる（PBI-16）。コピーと同じように、一覧の行から直接削除できるようにする。

## What Changes

- 一覧の各行（未完了・Done の両方）の右端、コピーの右に、削除のボタンを追加する。文字ではなくゴミ箱の線画アイコンで表示する。
- ボタンを押すと、詳細パネルの削除と同じ確認ダイアログ（「PBI-n を削除しますか？」）を出す。確認で「削除する」を選んだときだけ削除する。
- ボタンを押しても PBI の選択は変わらず、詳細パネルは開かない。ただし、削除した PBI の詳細パネルを開いていた場合は、パネルを閉じる。
- 詳細パネルの「削除」は、これまでどおり残す。
- 狭い画面（幅 560px 以下）では、2段目の末尾（コピーの後ろ）に並べる。

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `pbi-backlog`: 「PBI の削除」に一覧の行からの削除を加える。「一覧の行の表示」「狭い画面の一覧の行」「行の右側の項目の並び」に削除のボタンを加える。

## Impact

- `src/components/BacklogTable.tsx` と `BacklogTable.module.css`: 削除の列とボタンを追加する。
- `src/App.tsx`: 確認ダイアログを出し、確定で削除する。開いている PBI を消したらパネルを閉じる。
- `docs/design-principles.md`: 行の操作のルールに、削除のアイコンを例外として追記する（コピーと同じ扱い）。
- 保存形式・同期・ID の採番（削除した番号は再利用しない）は変わらない。
