## MODIFIED Requirements

### Requirement: PBI の詳細表示と編集
システムは、PBI を選択するとその ID、タイトル、カテゴリ、説明、受入条件、ステータス、ストーリーポイントを表示し、ID 以外の項目を編集できるように SHALL する。編集でもタイトルは前後の空白を除いて1文字以上でなければならない。受入条件は複数行の自由記述で、空でもよく、入力された内容をそのまま保存する。受入条件の入力欄は説明の下に「受入条件」のラベルを付けて置き、説明と同じく保存の操作で保存する。保存の操作（保存ボタン、またはタイトル欄での Enter）で保存できたときは、詳細パネルを閉じ、閉じるボタンで閉じたときと同じく URL から PBI の指定を外す。入力に誤りがあって保存できなかったときは、詳細パネルを開いたまま、入力した内容とエラーを表示する。ステータスの変更は保存の操作を待たずに反映し、詳細パネルは閉じない。

#### Scenario: タイトルと説明を編集する
- **WHEN** ユーザーが `PBI-2` を開き、タイトルと説明を変更して保存する
- **THEN** `PBI-2` のタイトルと説明が更新され、ID とバックログ上の位置は変わらない

#### Scenario: 保存すると詳細パネルが閉じる
- **WHEN** ユーザーが `PBI-2` の詳細パネルで説明を変更し、保存ボタンを押す
- **THEN** `PBI-2` の説明が保存され、詳細パネルが閉じて一覧だけが表示され、URL から `PBI-2` の指定が外れる

#### Scenario: タイトル欄の Enter で保存しても閉じる
- **WHEN** ユーザーが `PBI-2` の詳細パネルでタイトルを変更し、タイトル欄で Enter を押す
- **THEN** `PBI-2` のタイトルが保存され、詳細パネルが閉じる

#### Scenario: 保存できなかったときは閉じない
- **WHEN** ユーザーが詳細パネルでストーリーポイントに -1 を入力し、保存ボタンを押す
- **THEN** 値は保存されず、詳細パネルは開いたまま、入力した内容とエラーが表示される

#### Scenario: ステータスを変えても閉じない
- **WHEN** ユーザーが `PBI-2` の詳細パネルでステータスを `In Progress` に変更する
- **THEN** `PBI-2` のステータスが変わり、詳細パネルは開いたまま `PBI-2` を表示している

#### Scenario: カテゴリを変更する
- **WHEN** ユーザーがカテゴリ `タスク` の `PBI-2` を開き、カテゴリを `セキュリティ` に変更して保存する
- **THEN** `PBI-2` のカテゴリが `セキュリティ` になり、一覧の行のアイコンがセキュリティのアイコンに変わる。ID とバックログ上の位置は変わらない

#### Scenario: タイトルを空にして保存しようとする
- **WHEN** ユーザーが編集中にタイトルを空にして保存しようとする
- **THEN** 変更は保存されず、タイトルが必要であることが表示される

#### Scenario: 受入条件を書いて保存する
- **WHEN** ユーザーが `PBI-2` を開き、受入条件に「- ログインできる\n- 誤ったパスワードではエラーが出る」を入力して保存する
- **THEN** `PBI-2` の受入条件がその2行のとおりに保存され、開き直しても同じ内容が表示される

#### Scenario: 受入条件だけを変更する
- **WHEN** ユーザーが詳細パネルで受入条件だけを変更する
- **THEN** 保存ボタンが押せるようになり、保存すると受入条件だけが更新される

#### Scenario: 受入条件が空の PBI
- **WHEN** ユーザーが受入条件を一度も書いていない PBI の詳細パネルを開く
- **THEN** 「受入条件」のラベルと空の入力欄が表示される

#### Scenario: 作成した PBI の受入条件
- **WHEN** ユーザーが作成欄からタイトルだけを入力して PBI を作成する
- **THEN** その PBI の受入条件は空になる
