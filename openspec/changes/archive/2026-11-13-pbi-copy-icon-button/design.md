# Design

## Context

コピーボタンは `BacklogTable.tsx` の `RowCells` にあり、`idle / copied / failed` の状態に応じて文字（`COPY_LABELS`）を出している。状態の切り替え（2秒で戻す）と、結果を読み上げる `role="status"` の領域は別に実装済みで、見た目だけを文字から変える。列の幅は `.copyCol`（62px）と `.copy`（54px、「コピー失敗」が収まる幅）で決めている。アイコンは inline SVG で描く方針（design-principles の例外）で、`CategoryIcon` などの前例がある。

## Goals / Non-Goals

**Goals:**
- コピーを、四角を2つ重ねたアイコンのボタンにする。成功・失敗もアイコンの変化で示す。
- 既存の動作（クリップボード書き込み、詳細パネルを開かない、結果の読み上げ）を変えない。

**Non-Goals:**
- 詳細パネルなど、ほかの場所にコピー操作を足さない。
- アイコンライブラリを依存に追加しない。
- コピーする内容（Markdown の形）やリンクは変えない。

## Decisions

- **アイコンは inline SVG（16px、`currentColor`、線画）で、`BacklogTable.tsx` に小さなコンポーネントとして置く。** 依存を増やさず、色を CSS の `color` で `--text-muted` / `--text` に切り替えられる。代案のアイコンライブラリは、1個のために入れる量ではないので採らない。
- **成功はチェックの SVGに差し替え、失敗は同じアイコンの色を `--danger` にする。** 文字を出さない代わりに、成功は形、失敗は色で区別する。形だけ・色だけに頼らないため、読み上げの結果表示（既存の `role="status"`）は残す。失敗にも別の形（×）を使う案もあるが、「押したがコピーされていない」ことが形で変わらないほうが再試行の操作を迷わないので、色の変化にとどめる。赤は design-principles の「保存失敗などエラー表示だけ」に当たる。
- **普段は muted、行 hover・focus で本文色にする。** 文字のときの下線は、アイコンでは使えないので外す。タッチ端末でも常に見えるよう、hover だけで出し入れしない（既存ルールを維持）。フォーカスリングは `--accent` を使う。
- **ボタンの当たり判定は 24×24px にし、アイコンは 16px にする。** 文字のとき（54×約16px）より押しやすくする。列の幅は 24px にし、SP との間隔 8px は既存の `padding`・`column-gap` のまま保つ。
- **名前は `aria-label` の「PBI-3 をコピー」のまま、`title="コピー"` でツールチップを付ける。** 既存のテストの `getByRole('button', { name })` はそのまま通る。
- **`docs/design-principles.md` は「行の操作（コピーなど）は文字のボタン」のルールを改め、コピーを例外に加える。** アイコンは文字なしで機能するもの（並べ替えの持ち手と同じ）として、飾りのアイコンには当たらない。

## Risks / Trade-offs

- [アイコンだけでは用途が伝わらない] → 四角を2つ重ねた形は広く通じる。`title` と読み上げ名で補う。
- [失敗が色だけの変化で気づきにくい] → 読み上げの結果表示は残す。赤は本文の muted と明度差をつけて見分けられるようにし、実画面で確認する。
- [列を狭めたあと、2段の行のグリッドがずれる] → `grid-template-columns` の `auto` 列で内容なりに詰まる。390px 幅で ID・ステータス・SP の位置が変わらないことを実画面で確認する。
