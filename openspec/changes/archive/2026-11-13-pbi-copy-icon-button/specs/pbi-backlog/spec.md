## MODIFIED Requirements

### Requirement: 行の右側の項目の並び
システムは、一覧の行のステータス・ストーリーポイント・コピーのアイコンを互いに 8px 前後の間隔で詰めて並べ、その間隔をステータスの種類によらず一定に表示 SHALL する。1段の行では3つを行の右端に右揃えでまとめ、幅 560px 以下の2段の行では2段目の ID の後ろに左から並べる。

#### Scenario: ステータスと SP の間隔が揃う
- **WHEN** 1440×900 の画面で、「In Progress」の行と「To Do」の行が並んだ一覧を見る
- **THEN** どちらの行も、ステータスのラベルの右端から SP のバッジの左端までの距離が同じになる

#### Scenario: SP とコピーの間を詰める
- **WHEN** 1440×900 の画面で一覧を見る
- **THEN** どの行も、SP のバッジの右端からコピーのアイコンの左端までが 8px 前後になる

#### Scenario: スマホの2段目でも間隔が揃う
- **WHEN** 390×844 の画面で、「In Progress」の行と「To Do」の行が並んだ一覧を見る
- **THEN** どちらの行も、2段目でステータス・SP・コピーが ID の後ろに左から並び、ステータスの右端から SP のバッジの左端までの距離が同じになる
