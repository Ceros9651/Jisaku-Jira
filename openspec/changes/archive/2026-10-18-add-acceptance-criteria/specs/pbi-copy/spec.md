## MODIFIED Requirements

### Requirement: コピーする Markdown の形
コピーする文字列は、次の形の Markdown で SHALL ある。1行目は `## ` に続けて ID とタイトル。空行を挟んで、リンク・ステータス・ストーリーポイントを箇条書きにする。ステータスは画面と同じ表記（To Do / In Progress / Done）、ストーリーポイントが未設定なら「未設定」とする。続けて `### 説明` の見出しと説明の本文を置き、説明が空なら本文は「（なし）」とする。最後に `### 受入条件` の見出しと受入条件の本文を置き、受入条件が空なら本文は「（なし）」とする。説明と受入条件の本文は、入力された内容の前後の空白を除いてそのまま入れる。

```
## PBI-3 ログイン画面を作る

- リンク: https://ceros9651.github.io/Jisaku-Jira/#PBI-3
- ステータス: In Progress
- ストーリーポイント: 5

### 説明

メールアドレスとパスワードでログインできる。

### 受入条件

- 正しいメールアドレスとパスワードでログインできる
- 誤ったパスワードではエラーが表示される
```

#### Scenario: すべての項目がある PBI
- **WHEN** タイトル「ログイン画面を作る」、ステータス `In Progress`、SP 5、説明「メールアドレスとパスワードでログインできる。」、受入条件「- 正しいメールアドレスとパスワードでログインできる\n- 誤ったパスワードではエラーが表示される」の `PBI-3` をコピーする
- **THEN** 上の例と同じ文字列がクリップボードに入る

#### Scenario: SP と説明が空の PBI
- **WHEN** SP が未設定で、説明と受入条件が空の `PBI-1` をコピーする
- **THEN** ストーリーポイントの行は「- ストーリーポイント: 未設定」、説明と受入条件の本文はどちらも「（なし）」になる

#### Scenario: 開いているページの URL がリンクになる
- **WHEN** ユーザーが `http://localhost:5173/Jisaku-Jira/?reload=1#PBI-2` を開いた状態で `PBI-5` をコピーする
- **THEN** リンクの行は「- リンク: http://localhost:5173/Jisaku-Jira/#PBI-5」になる
