# Spec Delta

## MODIFIED Requirements

### Requirement: コピーする Markdown の形
コピーする文字列は、次の形の Markdown で SHALL ある。1行目は `## ` に続けて ID とタイトル。空行を挟んで、リンク・カテゴリ・ステータス・ストーリーポイントを箇条書きにする。カテゴリは画面と同じ表記（タスク / バグ / テスト / セキュリティ）、ステータスは画面と同じ表記（To Do / In Progress / Done）、ストーリーポイントが未設定なら「未設定」とする。最後に `### 説明` の見出しと説明の本文を置き、説明が空なら本文は「（なし）」とする。説明の本文は入力された内容をそのまま入れる。

```
## PBI-3 ログイン画面を作る

- リンク: https://ceros9651.github.io/Jisaku-Jira/#PBI-3
- カテゴリ: タスク
- ステータス: In Progress
- ストーリーポイント: 5

### 説明

メールアドレスとパスワードでログインできる。
```

#### Scenario: すべての項目がある PBI
- **WHEN** タイトル「ログイン画面を作る」、カテゴリ `タスク`、ステータス `In Progress`、SP 5、説明「メールアドレスとパスワードでログインできる。」の `PBI-3` をコピーする
- **THEN** 上の例と同じ文字列がクリップボードに入る

#### Scenario: カテゴリがバグの PBI
- **WHEN** カテゴリ `バグ` の `PBI-4` をコピーする
- **THEN** リンクの行の次に「- カテゴリ: バグ」の行が入る

#### Scenario: SP と説明が空の PBI
- **WHEN** SP が未設定で説明が空の `PBI-1` をコピーする
- **THEN** ストーリーポイントの行は「- ストーリーポイント: 未設定」、説明の本文は「（なし）」になる

#### Scenario: 開いているページの URL がリンクになる
- **WHEN** ユーザーが `http://localhost:5173/Jisaku-Jira/?reload=1#PBI-2` を開いた状態で `PBI-5` をコピーする
- **THEN** リンクの行は「- リンク: http://localhost:5173/Jisaku-Jira/#PBI-5」になる
