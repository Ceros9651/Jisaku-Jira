# Proposal

## Why

今の画面は、色・余白・部品を Jira に「倣った」だけで、本家の Jira（ユーザーが共有したバックログ画面のスクリーンショット）と並べると別のアプリに見える。上部のナビゲーション、パンくずと大きな見出し、薄いグレーの区画に入った一覧、右端に貼り付いた詳細パネルといった、Jira を Jira らしく見せている骨格が無いためである。Jira に慣れた人がそのまま迷わず使えるよう、機能は変えずに見た目と配置を本家に寄せる。

## What Changes

- 画面の骨格を Jira のバックログ画面の構成にする。上から、白地に下罫線の上部ナビゲーション（アプリのアイコンと名前、右にエクスポート・インポート）、パンくず「プロジェクト / <名前>」、24px の見出し、ビューのタブ（「バックログ」だけ、選択中）、その下に一覧の区画を置く。
- **BREAKING（操作）**: プロジェクトの切り替えを、ヘッダー下の文字タブの帯から、見出しの横の切り替えメニュー（作成順の一覧、選択中に印）に移す。プロジェクトの追加はこのメニューの末尾、名前の変更と削除は見出しの横の「…」メニューから行う。キーボードでも操作できる。
- 未完了の一覧と Done を、それぞれ薄いグレーの角丸の区画（Jira のスプリント／バックログの枠）に入れる。区画の見出しの行に、名前・件数（「n 件の PBI」）・SP 合計と、ステータス別の SP バッジを置く。行の表は区画の中の白地に 1px の枠で並べる。
- 一覧の行を Jira の行の見た目にする。PBI の種類を示す小さなアイコン、ID、タイトル、ステータス、灰色のバッジの SP（未設定は「-」）の順に並べる。Done の PBI の ID には取り消し線を引く。
- ステータスのラベルを、Jira の今のステータスボタンの形（大文字にせず、変更の矢印を常に表示）にする。色の3種（灰・青・緑）は変えない。
- PBI の作成欄を、未完了の区画の末尾の「+ 作成」の行にする（Jira のインライン作成と同じ位置）。一覧をスクロールしても画面下端に残す。
- 詳細パネルを、画面の右端に貼り付いた全高のパネル（左に罫線、角丸と枠の箱にしない）にする。先頭は種類のアイコン付きの ID と閉じるボタン、続いて 24px のタイトル、その下にステータス、「説明」「受入条件」の小見出しの区画、「詳細」としてストーリーポイントの行を置く。
- 色・文字のトークンを Atlassian のデザイントークンに近い寒色寄りの値にする（本文色、灰の段階、アクセントの青、罫線）。文字サイズに 24px を加える。欧文・数字の書体を、Atlassian Sans に近い Inter（Google Fonts）にする。Atlassian Sans は配布とライセンスの制約で使えないため代わりに使う。和文は今のシステムフォントのままにする。
- `docs/design-principles.md` を改訂する。今回の変更で必要になる、機能を持つアイコン・一覧の区画の角丸・上部ナビゲーションなどを「例外」として追記し、置き換わるルール（文字だけのタブ、文字サイズの4段階など）を書き換える。絵文字・グラデーション・強い影の禁止はそのまま残す。
- データ、保存、同期、リンク、コピー、並べ替えの動作は変えない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `projects`: プロジェクトの切り替えをタブの帯から見出しの横の切り替えメニューに変える。作成・名前変更・削除の操作の置き場所と、それに伴うシナリオの言い回しを変える。
- `pbi-backlog`: 画面の構成（上部ナビゲーション・パンくず・見出し・ビューのタブ・区画）を加え、一覧の行・ステータスのラベル・SP 集計の位置・作成欄の位置・詳細パネルの見出しと配置・Done エリアの見た目の要件を変える。

## Impact

- 画面: `src/App.tsx`・`src/App.module.css`（上部ナビゲーション、パンくず、見出し、ビューのタブ、区画、全高の詳細パネルのレイアウト）
- 部品: `src/components/BacklogTable.*`（種類のアイコン、SP バッジ、Done の取り消し線）、`StatusSelect.module.css`（矢印を常に表示、大文字をやめる）、`CreatePbiForm.*`（区画末尾の「+ 作成」の行）、`DetailPanel.*`（全高パネル、小見出しの区画）
- プロジェクトの切り替え: `src/components/ProjectTabs.*` を、切り替えメニューと「…」メニューの部品に置き換える。`ProjectNameForm` は再利用する
- トークンと書体: `src/styles/tokens.css`、`src/styles/global.css`、`index.html`（Google Fonts の Inter の読み込み）
- テスト: `src/App.test.tsx` のプロジェクトのタブ（`role="tab"`、左右の矢印、「プロジェクトを追加」ボタン）に依存するテストを、切り替えメニューの操作に書き換える
- 文書: `docs/design-principles.md`
- npm の依存の追加は無い（Inter は Google Fonts から読み込む）。データ形式・Firestore・URL は変えない
