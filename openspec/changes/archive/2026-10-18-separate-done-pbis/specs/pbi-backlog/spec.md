# Spec Delta

## MODIFIED Requirements

### Requirement: バックログ一覧の表示
システムは、選んでいるプロジェクトの PBI を、ステータスが `To Do` または `In Progress` の PBI を並べる一覧（以下、未完了の一覧）と、その下の Done エリアに分けて表示 SHALL する。未完了の一覧には `Done` の PBI を表示しない。どちらもバックログの並び順で並べ、各行には ID、タイトル、ステータス、ストーリーポイントを表示する。一覧の見出しにはプロジェクトの名前を表示し、その上部には選んでいるプロジェクトの `To Do` と `In Progress` の PBI の件数と、そのストーリーポイントの合計を表示する。

#### Scenario: 一覧を開く
- **WHEN** ユーザーがバックログ画面を開く
- **THEN** 選んでいるプロジェクトの `To Do` と `In Progress` の PBI がバックログの並び順で、ID・タイトル・ステータス・ストーリーポイントとともに未完了の一覧に表示され、`Done` の PBI は未完了の一覧に表示されない

#### Scenario: 件数と合計
- **WHEN** 選んでいるプロジェクトに `To Do` でストーリーポイント 3、`In Progress` で 5、`To Do` で未設定、`Done` で 2 の PBI が4件あり、他のプロジェクトに `To Do` で SP 8 の PBI が1件ある
- **THEN** 一覧の上部に件数 3 とストーリーポイント合計 8 が表示される

#### Scenario: PBI がないとき
- **WHEN** 選んでいるプロジェクトに PBI が1件もない
- **THEN** PBI がないことと、PBI を作成する操作が表示され、Done エリアは表示されない

#### Scenario: 未完了の PBI がないとき
- **WHEN** 選んでいるプロジェクトの PBI がすべて `Done` である
- **THEN** 未完了の一覧の位置に未完了の PBI がないことが表示され、その下の Done エリアにすべての PBI が表示される。見出しの件数は 0、合計は 0 になる

### Requirement: ステータス
PBI のステータスは `To Do`、`In Progress`、`Done` のいずれかで SHALL ある。ユーザーは未完了の一覧、Done エリア、詳細のどこからでもステータスを変更できる。ステータスを `Done` に変えた PBI はすぐに Done エリアに移り、`Done` から `To Do` または `In Progress` に変えた PBI はすぐに未完了の一覧に戻る。移ってもバックログの並び順は変わらないため、未完了の一覧に戻った PBI は、`Done` にする前と同じ前後関係の位置に表示される。

#### Scenario: 一覧からステータスを変更する
- **WHEN** ユーザーが一覧で `PBI-1` のステータスを `In Progress` に変更する
- **THEN** `PBI-1` のステータスが `In Progress` になり、一覧の表示に反映される

#### Scenario: Done にすると Done エリアに移る
- **WHEN** 未完了の一覧に `PBI-1`, `PBI-2`, `PBI-3` が並んでいるときに、ユーザーが一覧で `PBI-2` のステータスを `Done` に変更する
- **THEN** 未完了の一覧は `PBI-1`, `PBI-3` になり、`PBI-2` は Done エリアに表示される

#### Scenario: 詳細から Done にしても移る
- **WHEN** ユーザーが `PBI-2` の詳細パネルでステータスを `Done` に変更する
- **THEN** `PBI-2` は未完了の一覧から消えて Done エリアに表示され、詳細パネルは開いたまま `PBI-2` を表示している

#### Scenario: Done から戻すと元の位置に戻る
- **WHEN** バックログの並び順が `PBI-1`, `PBI-2`, `PBI-3` で `PBI-2` だけが `Done` のときに、ユーザーが Done エリアで `PBI-2` のステータスを `To Do` に変更する
- **THEN** `PBI-2` は Done エリアから消え、未完了の一覧は `PBI-1`, `PBI-2`, `PBI-3` の順になる

### Requirement: バックログの手動並べ替え
システムは、ユーザーが未完了の一覧で PBI のバックログ上の位置を、その PBI が属するプロジェクトの中で変更できるように SHALL する。並べ替えはポインター操作（ドラッグ）とキーボード操作の両方でできなければならない。並べ替えても他のプロジェクトの並び順は変わらず、未完了の一覧どうしの前後関係だけが変わる。Done エリアの PBI は並べ替えの対象にしない。並べ替えの結果は保存され、再読み込み後も保たれる。

#### Scenario: ドラッグで並べ替える
- **WHEN** 並び順が `PBI-1`, `PBI-2`, `PBI-3` のときに、ユーザーが `PBI-3` を先頭へドラッグする
- **THEN** 並び順が `PBI-3`, `PBI-1`, `PBI-2` になる

#### Scenario: キーボードで並べ替える
- **WHEN** ユーザーがキーボードで `PBI-1` を1つ下へ移動する操作をする
- **THEN** `PBI-1` と、未完了の一覧で直後に表示されている PBI の順序が入れ替わる

#### Scenario: Done の PBI をまたいで並べ替える
- **WHEN** バックログの並び順が `PBI-1`, `PBI-2`, `PBI-3` で `PBI-2` が `Done` のとき（未完了の一覧は `PBI-1`, `PBI-3`）に、ユーザーが `PBI-3` を未完了の一覧の先頭へドラッグする
- **THEN** 未完了の一覧は `PBI-3`, `PBI-1` になり、`PBI-2` は Done エリアに表示されたままになる

#### Scenario: Done エリアでは並べ替えられない
- **WHEN** ユーザーが Done エリアの行を見る
- **THEN** その行には並べ替えの持ち手が表示されず、ドラッグやキーボードで位置を変えられない

#### Scenario: 並び順は再読み込み後も保たれる
- **WHEN** ユーザーが並べ替えた後にページを再読み込みする
- **THEN** 並べ替えた後の順序で一覧が表示される

### Requirement: ステータス別の SP 集計
システムは、一覧の見出しの行に、件数と SP 合計に加えて、ステータスごとの SP 合計を表示 SHALL する。件数と SP 合計は `To Do` と `In Progress` の PBI だけで数え、ステータスごとの合計は `Done` を含む3つのステータスすべてについて表示する。ステータスごとの合計は、ステータスのラベルと同じ色で区別し、どのステータスの値かを文字でも読めるようにする。集計の文字は本文に近い濃さで表示する。

#### Scenario: ステータスごとの合計
- **WHEN** 一覧に Done で SP 3、In Progress で SP 5、To Do で SP 2、To Do で SP 未設定の PBI がある
- **THEN** 見出しの行に「3 件」「7 pt」と、To Do 2・In Progress 5・Done 3 が表示される

## ADDED Requirements

### Requirement: Done エリア
システムは、選んでいるプロジェクトに `Done` の PBI が1件以上あるとき、未完了の一覧の下に Done エリアを表示 SHALL する。Done エリアは折りたたまず、常に開いた状態で表示する。Done エリアの見出しには「Done」と、そのプロジェクトの `Done` の PBI の件数とストーリーポイントの合計を表示する。Done エリアの行は未完了の一覧と同じ列（ID、タイトル、ステータス、ストーリーポイント、コピー）を持ち、行を選ぶと詳細パネルが開く。`Done` の PBI が1件も無いときは Done エリアを表示しない。

#### Scenario: Done エリアの見出し
- **WHEN** 選んでいるプロジェクトに `Done` で SP 3 と `Done` で SP 未設定の PBI があり、他のプロジェクトに `Done` で SP 5 の PBI がある
- **THEN** 未完了の一覧の下に「Done」の見出しとともに件数 2 と SP 合計 3 が表示され、2件の PBI がバックログの並び順で並ぶ

#### Scenario: 常に開いている
- **WHEN** ユーザーが `Done` の PBI があるプロジェクトのバックログ画面を開く
- **THEN** Done エリアの PBI の行は、何も操作しなくても表示されている

#### Scenario: Done エリアから詳細を開く
- **WHEN** ユーザーが Done エリアの `PBI-2` のタイトルを押す
- **THEN** `PBI-2` の詳細パネルが開く

#### Scenario: Done の PBI が無いとき
- **WHEN** 選んでいるプロジェクトに `Done` の PBI が1件もない
- **THEN** Done エリアとその見出しは表示されない
