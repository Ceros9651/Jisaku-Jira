# pbi-copy Specification

## Purpose
PBI を1つの URL で指し示せるようにし、一覧から PBI のリンクと内容をまとめてクリップボードへコピーできるようにする。AI のチャットなどに PBI をそのまま貼って渡すために使う。

## Requirements

### Requirement: PBI のリンク
システムは、各 PBI を `<アプリの URL>#PBI-<番号>` の形の URL で指し示せるように SHALL する。`<アプリの URL>` は、いま開いているアプリのページの URL から、クエリ文字列とハッシュを除いたものとする。PBI の番号は全プロジェクトで重複しないため、リンクにプロジェクトは含めない。このリンクを開くと、その PBI が属するプロジェクトのタブが選ばれ、その PBI の詳細パネルが開いた状態でバックログ画面が表示される。リンクの番号の PBI がそのブラウザのどのプロジェクトにも無い場合は、詳細パネルを開かずに、最後に開いていたプロジェクトの一覧だけを表示する。

#### Scenario: リンクで PBI を開く
- **WHEN** `PBI-3` があるバックログで、ユーザーが `https://ceros9651.github.io/Jisaku-Jira/#PBI-3` を開く
- **THEN** 一覧が表示され、`PBI-3` の詳細パネルが開いている

#### Scenario: 別のプロジェクトの PBI のリンク
- **WHEN** 最後に開いていたプロジェクトが「Web」で、`PBI-3` が「Tool」にあるときに、ユーザーが `…/Jisaku-Jira/#PBI-3` を開く
- **THEN** 「Tool」のタブが選ばれて「Tool」の一覧が表示され、`PBI-3` の詳細パネルが開いている

#### Scenario: 無い PBI のリンク
- **WHEN** `PBI-9` がどのプロジェクトにも無いバックログで、ユーザーが `…/Jisaku-Jira/#PBI-9` を開く
- **THEN** 最後に開いていたプロジェクトの一覧だけが表示され、詳細パネルは開かない

### Requirement: 一覧から PBI をコピーする
システムは、一覧の各行の右端に、その PBI をコピーするボタンを表示 SHALL する。ボタンには「コピー」と文字で表示し、読み上げでは「PBI-<番号> をコピー」として識別できるようにする。ボタンを押すと、その PBI のリンクと内容を Markdown にまとめた文字列をクリップボードに書き込む。ボタンを押しても PBI の選択は変わらず、詳細パネルは開かない。

#### Scenario: コピーボタンを押す
- **WHEN** ユーザーが一覧で `PBI-3` の行のコピーボタンを押す
- **THEN** `PBI-3` のリンクと内容の Markdown がクリップボードに入る

#### Scenario: コピーしても詳細パネルは開かない
- **WHEN** 詳細パネルを閉じた状態で、ユーザーが `PBI-3` の行のコピーボタンを押す
- **THEN** 詳細パネルは閉じたままで、URL のハッシュも変わらない

### Requirement: コピーする Markdown の形
コピーする文字列は、次の形の Markdown で SHALL ある。1行目は `## ` に続けて ID とタイトル。空行を挟んで、リンク・ステータス・ストーリーポイントを箇条書きにする。ステータスは画面と同じ表記（To Do / In Progress / Done）、ストーリーポイントが未設定なら「未設定」とする。最後に `### 説明` の見出しと説明の本文を置き、説明が空なら本文は「（なし）」とする。説明の本文は入力された内容をそのまま入れる。

```
## PBI-3 ログイン画面を作る

- リンク: https://ceros9651.github.io/Jisaku-Jira/#PBI-3
- ステータス: In Progress
- ストーリーポイント: 5

### 説明

メールアドレスとパスワードでログインできる。
```

#### Scenario: すべての項目がある PBI
- **WHEN** タイトル「ログイン画面を作る」、ステータス `In Progress`、SP 5、説明「メールアドレスとパスワードでログインできる。」の `PBI-3` をコピーする
- **THEN** 上の例と同じ文字列がクリップボードに入る

#### Scenario: SP と説明が空の PBI
- **WHEN** SP が未設定で説明が空の `PBI-1` をコピーする
- **THEN** ストーリーポイントの行は「- ストーリーポイント: 未設定」、説明の本文は「（なし）」になる

#### Scenario: 開いているページの URL がリンクになる
- **WHEN** ユーザーが `http://localhost:5173/Jisaku-Jira/?reload=1#PBI-2` を開いた状態で `PBI-5` をコピーする
- **THEN** リンクの行は「- リンク: http://localhost:5173/Jisaku-Jira/#PBI-5」になる

### Requirement: コピーの結果の表示
コピーに成功したら、システムは押したボタンの文字を「コピー済み」に変えて SHALL 知らせ、約2秒後に「コピー」に戻す。成功と失敗は読み上げでも伝わるようにする。クリップボードに書き込めなかった場合は、ボタンの文字を「コピー失敗」に変えて、同じく約2秒後に戻す。

#### Scenario: コピーに成功する
- **WHEN** ユーザーが `PBI-3` のコピーボタンを押し、クリップボードへの書き込みが成功する
- **THEN** そのボタンの文字が「コピー済み」になり、約2秒後に「コピー」に戻る

#### Scenario: コピーに失敗する
- **WHEN** ユーザーが `PBI-3` のコピーボタンを押し、クリップボードへの書き込みが失敗する
- **THEN** そのボタンの文字が「コピー失敗」になり、バックログの内容は変わらない
