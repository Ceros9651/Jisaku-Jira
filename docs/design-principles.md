# デザイン方針

このアプリのUIで守るルール。/ui-review で採用した修正方針がここに蓄積される。
新しい画面やコンポーネントを作るときも、このファイルに従うこと。

- ルールは「何をどうするか」を一行で書く（例: 一覧の区切りはカードではなく1pxの罫線）。
- 各ルールの末尾に由来の change 名を付ける。
- 例外を作るときは、ルールを消さずに例外として追記する。

## 形と区切り

- バックログ一覧は表形式にし、行の区切りは 1px の罫線にする。行を1つずつカードで包まない。（add-pbi-backlog）
- 未完了の一覧と Done は、それぞれ薄いグレー（`--surface-sunken`）の 8px 角丸の区画に入れ、行の表は区画の中で白地・1px の枠・4px 角丸にする。表の列の見出しは読み上げ用にだけ残す。（jira-like-ui）
- 箱（枠線＋背景）で囲むのは、一覧の区画、確認ダイアログ、メニュー、警告帯、詳細パネルの中の「詳細」の区画だけにする。（add-pbi-backlog、jira-like-ui）
- 角丸は入力欄・ボタン・ステータス・一覧の表が 4px、ダイアログ・メニュー・「詳細」の区画が 6px、一覧の区画が 8px。一覧の行には付けない。（add-pbi-backlog、jira-like-ui）
- 影は実際に上に重なるもの（ダイアログ、メニュー、ドラッグ中の行）だけに付ける。（add-pbi-backlog、jira-like-ui）
- 作成欄は、未完了の区画の末尾に一覧の行と同じ高さの「+ 作成」の行として置き、スクロールしても画面の下端に残す。塗りつぶしたボタンは置かない。（ui-refine-backlog、jira-like-ui）行の先頭は `+` の代わりにカテゴリの選択（選んでいるカテゴリのアイコンと文字だけの select）にする。（add-pbi-category）
- 行の右側の項目（ステータス・SP・コピー）は、1段の行では右揃えにし、幅 560px 以下の2段の行では2段目の ID の後ろに左から並べる。どちらも 8px 前後の間隔で詰め、間隔をステータスの種類で変えない。（ui-refine-backlog-2）
- 幅 560px 以下では一覧の行を2段にし、タイトルを1段目の幅いっぱいに、カテゴリのアイコン・ID・ステータス・SP・コピーを2段目に並べる。DOM の順は変えない。（ui-refine-backlog-2、add-pbi-category）
- プロジェクトの切り替えは、見出しの右の下向き矢印のボタンから開くメニューで行う。作成した順に並べ、選択中はチェックとアクセント色の文字で示し、末尾に区切り線と「プロジェクトを追加」を置く。（jira-like-ui）


## 色と階層

- 色は無彩色の段階（`--gray-*`）を主にし、アクセント色は1色（`--accent`）だけにする。値は Atlassian のデザイントークンに近い寒色寄りにする。（add-pbi-backlog、jira-like-ui）
- アクセント色を使うのは主ボタン、選択中の行、選択中のビューのタブ、メニューの選択中の項目、フォーカスリング、リンクだけ。（add-pbi-backlog、add-project-tabs、jira-like-ui、add-pbi-category）
- ステータスは文字ラベル（To Do / In Progress / Done）で区別し、色は補助にとどめる。色を使うのはステータス表示だけ。（add-pbi-backlog）
- 警告とエラーの赤・黄は、保存失敗・読み込みエラー・入力エラーの表示にだけ使う。（add-pbi-backlog）
- 階層は影ではなく、背景の明度差と罫線で示す。グラデーションは使わない。（add-pbi-backlog）
- ステータスは文字幅に合わせた Jira のステータスボタンの形（薄い背景、大文字にしない 12px/600 の文字、右端に常に下向きの矢印）で表し、一覧と詳細パネルで同じ見た目にする。（ui-refine-backlog、jira-like-ui）
- 区画の見出しの行に「n 件の PBI」と SP 合計を置き、未完了の区画では右端にステータス別の SP をステータスと同じ色の小さなバッジで並べる。集計の文字は本文に近い濃さ（gray-700）にする。（ui-refine-backlog、jira-like-ui）
- 一覧の行の SP は灰色の小さなバッジにし、未設定は「-」を出す。Done の PBI の ID には取り消し線を引く。（jira-like-ui）


## アイコンと文字

- 飾りのアイコンと絵文字は使わない。並べ替えの持ち手（⋮⋮ 相当の線画）のように文字なしで機能するものと、「例外」に挙げた Jira の文脈で意味を持つアイコンだけを使う。（add-pbi-backlog、jira-like-ui）
- アプリのアイコン（favicon・apple-touch-icon）は、アクセント色の地に白い札を 3 列（3・2・1 枚）並べたボードの形にする。色はアクセント色と白の 2 色だけで、グラデーションと影は付けない。16px の格子で描き、札の端を整数ピクセルに合わせる。（fix-app-icon）
- ID とストーリーポイントは等幅数字（`font-variant-numeric: tabular-nums`）にする。ストーリーポイントは右揃え。（add-pbi-backlog）
- 文字サイズは 12 / 13 / 14 / 18 / 24px の5段階。24px は画面の見出しと詳細パネルのタイトルだけに使う。（add-pbi-backlog、jira-like-ui）
- どの画面幅でも、文字は 12px 未満にしない。（ui-refine-backlog-2）
- 書体は、欧文・数字が Inter（Google Fonts）、和文がシステムフォント。Atlassian Sans は配布とライセンスの制約で使わない。Web フォントは Inter 以外を読み込まない。（jira-like-ui）
- 行の操作（コピーなど）はアイコンではなく文字のボタンにし、普段は muted、行 hover・focus で本文色と下線にする。タッチ端末でも押せるよう、hover だけで出し入れしない。（add-pbi-copy-link）
- プロジェクトへの操作（名前を変更・削除）は見出しの右の「…」メニューに置き、追加は切り替えのメニューの末尾に置く。名前の入力は見出しの位置で入力欄に変える。（add-project-tabs、jira-like-ui）

## 余白とレイアウト

- 画面は左揃え。上から、白地に下罫線の上部ナビゲーション、パンくず「プロジェクト / <名前>」、24px の見出し、ビューのタブ、一覧の区画の順に置く（Jira のバックログと同じ構成）。中央寄せのランディング構成にしない。（add-pbi-backlog、jira-like-ui）
- 件数とストーリーポイント合計は区画の見出しの行に置く。（add-pbi-backlog、jira-like-ui）
- 余白は 4 / 8 / 12 / 16 / 24 / 32px の段階から選び、関係の近い要素は詰め、区切りたいところを広げる。一覧の行は詰めて表示する。（add-pbi-backlog）
- 空状態はイラストを使わず、短い文と作成の操作だけを示す。（add-pbi-backlog）
- バックログ一覧はコンテンツ領域の幅いっぱいに広げ、固定の最大幅を付けない。（ui-refine-backlog）
- 詳細パネルは画面の右端に貼り付けた全高のパネルにし、箱で包まず左の罫線だけで一覧と区切る。先頭はカテゴリのアイコン付きの ID と閉じるボタン、続けて枠の無い 24px のタイトル（枠は hover・focus のときだけ）、ステータス、「説明」「受入条件」の小見出しと入力欄、最後に「詳細」の区画にラベル左・値右の行で項目を並べる。（ui-refine-backlog、jira-like-ui）
- 詳細パネルの保存・削除の行はパネルの下端に貼り付け、白地と上の 1px の罫線で区切る。影は付けない。（ui-refine-backlog-2）
- Done の PBI は未完了の区画の下の Done の区画にまとめ、未完了と同じ形の区画・見出しの行・表で示す。折りたたみの矢印は使わない。未完了の区画の件数・合計は未完了だけで数える。（separate-done-pbis、jira-like-ui）


## 例外

- 本家 Jira に見た目を寄せるため、Jira の文脈で意味を持つアイコンに限り使う：PBI のカテゴリ（下記）、メニューを開く下向きの矢印、「…」、閉じる（×）、メニューの選択中のチェック。どれも inline SVG で、グラデーションと影は付けない。（jira-like-ui、add-pbi-category）
- 一覧の区画（未完了・Done）は薄いグレーの 8px 角丸で包み、行の表は区画の中で 1px の枠と 4px 角丸の白地にする。（jira-like-ui）
- 上部ナビゲーション・パンくず・ビューのタブを置き、プロジェクトの切り替えは見出しの横のメニューにする。ビューのタブは今はバックログだけで、押しても画面は変わらないのでリンクにしない。（jira-like-ui）
- 文字サイズに 24px（画面の見出し・詳細パネルのタイトル）を加える。（jira-like-ui）
- 欧文・数字の書体を Inter にする（和文はシステムフォント）。Web フォントはこれ以外を読み込まない。（jira-like-ui）
- ステータス別の SP のバッジは、本文のルール（未完了の区画の右端に並べる）の例外として、各区画の右端にその区画の PBI だけで数えて並べる。未完了の区画は To Do・In Progress、Done の区画は Done だけになり、バッジの合計は区画の「n pt」と一致する。（ui-refine-backlog-2）
- 一覧の ID の左に置くカテゴリのアイコンは、文字の列を足さずに PBI の種類を一目で見分けるための機能を持つアイコンで、飾りのアイコンには当たらない。色と形（チェック・丸・フラスコ・錠前）の両方で区別し、カテゴリ名を読み上げとツールチップ（SVG の `<title>`）で示す。（add-pbi-category）
- カテゴリのアイコンの地の色（`--category-*`）は、ステータス以外で色を使う唯一の例外にする。使うのはカテゴリのアイコンの中だけで、行の背景や文字には使わない。バグの赤はエラーの赤（`--danger`）とは別の値にし、タスクの青もアクセント色とは別の値にする。（add-pbi-category）
