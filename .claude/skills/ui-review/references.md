# 参考アプリ（厳選リスト）

/ui-review が修正案を作るときに最優先で参照する、実在アプリの一覧。
初回の /ui-review 実行時に候補が提示され、選んだものがここに追記される。手で追加・削除してもよい。

## 書式

```
## <アプリ名>
- URL: <...>
- 参考にする画面: <画面名やURL>
- 参考にする点: <何をどう処理しているか。1〜3行>
- 追加日: YYYY-MM-DD
```

## Jira Software（Scrum バックログ）
- URL: https://support.atlassian.com/jira-software-cloud/docs/use-your-scrum-backlog/ （ステータス表示: https://atlassian.design/components/lozenge/examples ）
- 参考にする画面: Scrum ボードのバックログ画面（スプリント／バックログのセクションと右側の詳細表示）
- 参考にする点: 罫線区切りの密な一覧をドラッグで並べ替え、セクション末尾の「+ Create」でインライン作成し、選んだ項目の詳細を右側に出す（J/K で前後に移動）。ステータスは小さな文字ラベル（Lozenge）で、色は neutral／information／success の3種に絞る。
- 追加日: 2026-10-12
